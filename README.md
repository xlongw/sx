# EMA 均线形态股票筛选工具

基于 **EMA21 / EMA55 / EMA120** 三条指数移动平均线的技术形态筛选工具，使用 Python + Streamlit 构建。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

浏览器将自动打开 http://localhost:8501

### 3. 数据准备（首次启动）

- **首次启动**：工具会自动从 akshare 获取沪深主板股票最近 250 个交易日的日线数据，并缓存到本地 SQLite 数据库（`stock_data.db`）
- **后续启动**：直接从缓存读取数据（有效期 1 天），如需更新请点击侧边栏的 **【刷新数据】** 按钮
- 若 akshare 不可用，工具会自动 fallback 到 yfinance

## 功能说明

### 筛选条件

| 条件 | 名称 | 说明 |
|------|------|------|
| A | 首次站上三线 | 今日收盘价首次同时大于 EMA21、EMA55、EMA120（突破信号） |
| B | 均线粘合 | 三条 EMA 比值 ≤ 阈值（默认 1.02），且收盘价偏离均值 ≤ 3%（蓄势信号） |
| C | 低波动 | 股价在三条均线附近（偏离 < 阈值），且 ATR(5)/收盘价 < 3% 或 5日波幅 < 5%（窄幅整理信号） |

### 逻辑组合

- **OR（任一条件）**：满足任一勾选条件即触发信号（适合初筛）
- **AND（同时满足）**：需同时满足所有勾选条件（适合精选）

### K线图功能

- 在结果表格中选择股票，点击 **【查看K线图】** 按钮
- 显示最近 60 个交易日的 K 线图（红涨绿跌，国内习惯）
- 叠加三条 EMA 均线（蓝色 EMA21、橙色 EMA55、紫色 EMA120）
- 底部显示成交量柱状图
- 支持缩放、平移、悬停查看详情
- 信号触发日期有彩色标记：
  - 🔺 绿色三角：条件 A（首次站上三线）
  - 🟡 黄色圆点：条件 B（均线粘合）
  - 🔵 蓝色方块：条件 C（低波动）

## 验收测试用例

### 测试用例 1：中信证券 (600030) 2024年9月突破三线

**背景**：2024年9月下旬，受政策利好刺激，中信证券股价放量大涨，突破三条EMA均线。

**操作步骤**：
1. 在侧边栏勾选「使用自定义股票列表」，输入 `600030`
2. 仅勾选 **条件A**，逻辑选择 **OR**
3. 点击 **【开始筛选】**
4. 确认结果中包含 600030，信号日期应在 2024年9月24日附近

**预期结果**：条件 A 被触发，「信号日期」字段显示为 2024-09-24 或邻近交易日。

### 测试用例 2：中际旭创 (300308) 2023年12月均线粘合

**注意**：300308 属于创业板，如默认股票列表不包含创业板股票，请在自定义列表中手动添加 `300308`。

**背景**：2023年12月，中际旭创经历一波拉升后横盘整理，三条EMA均线相互靠拢形成粘合形态，随后向上发散。

**操作步骤**：
1. 勾选「使用自定义股票列表」，输入 `300308`
2. 仅勾选 **条件B**，粘合阈值保持默认 1.02
3. 逻辑选择 **OR**
4. 点击 **【开始筛选】**
5. 确认结果中能识别到 300308 的粘合信号

**预期结果**：条件 B 被触发，结果中显示「B-均线粘合」。

### 自测：平安银行 (000001) K线图

**操作步骤**：
1. 使用默认股票列表或自定义输入 `000001`
2. 执行筛选
3. 在下拉框中选择 000001，点击 **【查看K线图】** 按钮
4. 检查K线图：
   - 蜡烛图：上涨为红色，下跌为绿色（国内习惯）
   - EMA线：蓝色(21)、橙色(55)、紫色(120) 三条线平滑显示
   - 成交量柱状图与K线日期对齐
   - 空头排列时 EMA21 < EMA55 < EMA120
